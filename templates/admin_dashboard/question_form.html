How answers are checked

  • Gap filling — write the gap in the part text as (N) ______ (N = question number) and enter the accepted answers separated by |, e.g. 1990|nineteen ninety. Case, extra spaces, final punctuation and a leading “the/a/an” are ignored.
  • Multiple choice — add options A, B, C (D) and tick the correct one.
  • True / False / No Information — correct answer: TRUE, FALSE or NO INFORMATION.
  • Matching (statements / speakers) — the question is the text or speaker; list the statements A–J as options and enter the correct letter. Use the same option list for every question in the part.
  • Matching headings — the question is the paragraph; list the headings as options and enter the correct letter.
  • Map labelling — upload the map on the part, add letters A–I as options (text can stay empty) and enter the correct letter.
