How it works

  1. Copy the whole test from the PDF / Word file and paste it on the left — parts, texts, questions and options together.
  2. Paste the answer key if you have it.
  3. Preview shows what was found in every part: the text, each question, its type and answer.
  4. Create mock saves it as a draft. Then {% if section == 'listening' %}upload the audio for each part (and the map in Part 4) in ⚡ Quick entry and {% endif %}publish.

Question numbers that restart (e.g. Part 2 written as 1–8) are moved on automatically (7–14).
